# Task 1: Online Reservation System

## 📌 Project Overview
A Java GUI application built using Swing/JavaFX and JDBC with MySQL/SQLite for managing train reservations, bookings, auto-generated PNRs, and cancellations.

## 🏗️ Architecture
- Login System
- Passenger & Train Management
- PNR Generation & Confirmation
- Cancellation Module
- Database Storage (JDBC + SQLite)
